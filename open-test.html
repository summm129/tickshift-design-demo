株探を Firefox で開く試験

Samsung Internet で、上から1つずつ押してください。押したあと「選択画面が出たか（候補に Firefox があったか）」「どのアプリで株探のページが開いたか」を教えてください。開いたら戻ってきて次へ。

1. Firefox を指定いまの「株探で見る」の Chrome を Firefox に変えたもの 2. Firefox を指定（くわしく）「ページを見る」ことを明示したもの 3. Firefox の受け口を直接指定Firefox の中のリンクを受け取る画面を名指し 4. Firefox 専用の形式firefox:// で始まるリンク 5. いまの「株探で見る」（Chrome 指定）比べる用 6. 普通のリンク指定なし
